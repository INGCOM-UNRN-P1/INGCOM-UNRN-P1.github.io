# 0x5009h: Prohibición de división entera no intencional asignada a flotantes

```{admonition} Categoría: Compilación y Buenas Prácticas de Ingeniería (0x50XX)
:class: note
Código de regla: `0x5009h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Asignar el resultado de una división entre enteros a un float o double (ej: double d = 1 / 2) trunca a cero antes de la asignación. Usar literales flotantes (1.0 / 2).

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
double tasa = 1 / 2;
```

### Código Conforme (Recomendado)

```{code-block} c
double tasa = 1.0 / 2.0;
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
