# 0x5016h: Inclusión explícita obligatoria de cabeceras para funciones de biblioteca estándar

```{admonition} Categoría: Compilación y Buenas Prácticas de Ingeniería (0x50XX)
:class: note
Código de regla: `0x5016h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

El uso de funciones de la biblioteca estándar de C requiere la inclusión explícita de su cabecera oficial correspondiente (<stdio.h>, <stdlib.h>, <string.h>, <math.h>, etc.), prohibiendo depender de declaraciones implícitas obsoletas.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int main(void) {
    printf("hola"); // Invocación sin incluir <stdio.h>
    return 0;
}
```

### Código Conforme (Recomendado)

```{code-block} c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    printf("hola");
    return 0;
}
```
