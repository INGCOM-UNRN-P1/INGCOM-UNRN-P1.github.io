# 0x5008h: Prohibición de funciones obsoletas o inseguras (gets, atoi)

```{admonition} Categoría: Compilación y Buenas Prácticas de Ingeniería (0x50XX)
:class: note
Código de regla: `0x5008h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

El uso de gets() está estrictamente prohibido (removido en C11). atoi() no detecta errores de conversión; debe utilizarse strtol().

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
gets(buf);
int val = atoi(str);
```

### Código Conforme (Recomendado)

```{code-block} c
fgets(buf, sizeof(buf), stdin);
long val = strtol(str, &fin, 10);
```
