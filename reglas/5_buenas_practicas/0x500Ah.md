# 0x500Ah: Protección obligatoria de parámetros en macros funcionales mediante paréntesis

## Fundamentación y Justificación Pedagógica

Los parámetros en el cuerpo de una macro funcional (#define CUADRADO(x) ...) deben estar siempre encerrados entre paréntesis '((x) * (x))' para mitigar anomalías por precedencia de operadores.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
#define MULT(a, b) a * b
```

### Código Conforme (Recomendado)

```{code-block} c
#define MULT(a, b) ((a) * (b))
```
