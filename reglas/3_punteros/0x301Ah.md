# 0x301Ah: Validador de uso idiomático de tipos booleanos estándar

## Fundamentación y Justificación Pedagógica

Se debe utilizar el tipo estándar 'bool', 'true' y 'false' de <stdbool.h> en lugar de redefiniciones manuales obsoletas como 'typedef int BOOLEAN' o '#define TRUE 1'.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
typedef int BOOL;
#define TRUE 1
#define FALSE 0
```

### Código Conforme (Recomendado)

```{code-block} c
#include <stdbool.h>
bool activo = true;
```
