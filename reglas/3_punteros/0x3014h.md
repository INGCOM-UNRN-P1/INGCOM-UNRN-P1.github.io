(0x3014h)=
# 0x3014h: Prohibición de doble liberación de memoria (double free) sobre el mismo puntero

```{admonition} Categoría: Punteros y Gestión de Memoria (0x30XX)
:class: note
Código de regla: `0x3014h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Invocar 'free(ptr)' dos veces consecutivas sobre el mismo puntero corrompe el heap del asignador de memoria (glibc / jemalloc) y provoca abortos inmediatos (SIGABRT).

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
free(ptr);
free(ptr);
```

### Código Conforme (Recomendado)

```{code-block} c
free(ptr);
ptr = NULL;
```
