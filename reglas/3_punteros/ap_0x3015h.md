(ap_0x3015h)=
# Antipatrón AP-0x3015h: Sobreescritura directa de puntero en realloc

:::{admonition} Regla de Estilo Asociada: 0x3015h
:class: tip
La transgresión descripta en este antipatrón se encuentra normada por la **[0x3015h: Reallocación segura: no sobreescribir el puntero original directamente](0x3015h.md)**.
:::

```{admonition} Diagnóstico de Antipatrón
:class: warning
Código de auditoría: `AP-0x3015h` | Categoría: Punteros y Gestión de Memoria (0x30XX)
```


## Diagnóstico
Al asignar el retorno de realloc sobre la misma variable, si la reasignación falla se pierde la única referencia a la memoria previamente reservada.

## Justificación Pedagógica y de Estándar C
El código de diagnóstico `0x3015h` identifica una práctica desaconsejada en la arquitectura pedagógica de la materia.
Esta transgresión incrementa el acoplamiento, produce comportamiento indefinido o vulnera los invariantes de memoria.

## Sugerencia de Corrección
Utilizá una variable temporal: 'void *tmp = realloc(ptr, n); if (tmp) ptr = tmp;'.

## Ejemplos

### Código con Antipatrón (Incorrecto)
```c
ptr = realloc(ptr, nuevo_tam);
```

### Código Idiomático Refactorizado (Correcto)
```c
void *tmp = realloc(ptr, nuevo_tam);
if (tmp != NULL) ptr = tmp;
```
