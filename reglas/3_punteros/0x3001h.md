(0x3001h)=
# 0x3001h: Siempre verificá la asignación exitosa de memoria dinámica

```{admonition} Categoría: Punteros y Gestión de Memoria (0x30XX)
:class: note
Código de regla: `0x3001h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Toda asignación de memoria dinámica realizada con `malloc`, `calloc` o `realloc` debe ser seguida inmediatamente por una comprobación contra `NULL` antes de su uso.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
ptr = malloc(sizeof(*ptr));
ptr->dato = 10; // Falla si no hay memoria
```

### Código Conforme (Recomendado)

```{code-block} c
ptr = malloc(sizeof(*ptr));
if (ptr == NULL) {
    return NULL;
}
```
