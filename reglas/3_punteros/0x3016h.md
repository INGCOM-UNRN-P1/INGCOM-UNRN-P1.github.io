# 0x3016h: Orden incorrecto o sospechoso de argumentos en llamadas a memset

```{admonition} Categoría: Punteros y Gestión de Memoria (0x30XX)
:class: note
Código de regla: `0x3016h` | Soporta corrección automática: **Sí**
```

## Fundamentación y Justificación Pedagógica

En memset(ptr, val, size), el segundo argumento es el valor byte a escribir y el tercero es la cantidad de bytes. Invertir estos argumentos es un error pedagógico común que no inicializa la memoria.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
memset(buffer, sizeof(buffer), 0);
```

### Código Conforme (Recomendado)

```{code-block} c
memset(buffer, 0, sizeof(buffer));
```
