(0x300Dh)=
# 0x300Dh: Utilizá enum en lugar de "números mágicos" para conjuntos de estados y valores constantes

:::

```{admonition} Categoría: Punteros y Gestión de Memoria (0x30XX)
:class: note
Código de regla: `0x300Dh` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Las enumeraciones explican la semántica de un conjunto de constantes enteras relacionadas.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
for (int i = 0; i < 5; i++) // ¿Qué significa 5?
```

### Código Conforme (Recomendado)

```{code-block} c
#define MAX_INTENTOS 5
for (int i = 0; i < MAX_INTENTOS; i++)
```
