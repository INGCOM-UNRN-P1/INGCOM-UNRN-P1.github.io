(0x3009h)=
# 0x3009h: Documentá explícitamente los casos en que una función puede retornar NULL

```{admonition} Categoría: Punteros y Gestión de Memoria (0x30XX)
:class: note
Código de regla: `0x3009h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Si una función que devuelve un puntero puede fallar y retornar `NULL`, este escenario debe ser explícito en la documentación de retorno de la función.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
nodo_t *buscar(int id);
```

### Código Conforme (Recomendado)

```{code-block} c
/** @return Puntero al elemento, o NULL si no existe. */
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
