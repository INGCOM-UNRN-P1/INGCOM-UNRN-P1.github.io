(0x3017h)=
# 0x3017h: Orden canónico de calificadores: 'const tipo' en lugar de 'tipo const'

```{admonition} Categoría: Punteros y Gestión de Memoria (0x30XX)
:class: note
Código de regla: `0x3017h` | Soporta corrección automática: **Sí**
```

## Fundamentación y Justificación Pedagógica

Por convención institucional de cátedra, los calificadores const deben preceder al tipo de dato básico ('const int x' en lugar de 'int const x').

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int const MAXIMO = 100;
```

### Código Conforme (Recomendado)

```{code-block} c
const int MAXIMO = 100;
```
