# Antipatrón AP-0x3002h: Retorno de puntero a variable local (Dangling Stack Pointer)

:::{admonition} Regla de Estilo Asociada: 0x3002h
:class: tip
La transgresión descripta en este antipatrón se encuentra normada por la **[0x3002h: Liberá siempre la memoria dinámica y asigná NULL al puntero para mitigar punteros colgantes](0x3002h.md)**.
:::

```{admonition} Diagnóstico de Antipatrón
:class: warning
Código de auditoría: `AP-0x3002h` | Categoría: Punteros y Gestión de Memoria (0x30XX)
```


## Diagnóstico
Al finalizar la función, su stack frame se destruye. El puntero retornado apuntará a memoria inválida o sobrescribible.

## Justificación Pedagógica y de Estándar C
El código de diagnóstico `0x3002h` identifica una práctica desaconsejada en la arquitectura pedagógica de la materia.
Esta transgresión incrementa el acoplamiento, produce comportamiento indefinido o vulnera los invariantes de memoria.

## Sugerencia de Corrección
Asigná memoria dinámica con malloc() o pasá el buffer como parámetro por referencia.

## Ejemplos

### Código con Antipatrón (Incorrecto)
```c
int* fn(void) {
    int local = 42;
    return &local;
}
```

### Código Idiomático Refactorizado (Correcto)
```c
int* fn(void) {
    int *ptr = malloc(sizeof(*ptr));
    if (ptr) *ptr = 42;
    return ptr;
}
```
