(0x3004h)=
# 0x3004h: Utilizá typedef para definir tipos de estructuras con el sufijo _t

```{admonition} Categoría: Punteros y Gestión de Memoria (0x30XX)
:class: note
Código de regla: `0x3004h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Esto simplifica el manejo sintáctico del código en C. Los alias de tipo creados con `typedef` deben terminar obligatoriamente con el sufijo `_t`.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
typedef struct nodo Nodo;
```

### Código Conforme (Recomendado)

```{code-block} c
typedef struct nodo nodo_t;
typedef enum estado estado_t;
```
