(0x3011h)=
# 0x3011h: Si una función recibe un puntero genérico para operaciones de solo lectura, la firma de la función debe utilizar const void*

```{admonition} Categoría: Punteros y Gestión de Memoria (0x30XX)
:class: note
Código de regla: `0x3011h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Si una función recibe un puntero genérico `void*` y no modifica el contenido de la memoria apuntada, se **debe** declarar obligatoriamente el parámetro como `const void*`. Se prohíbe pasar `void*` sin calificador `const` si la operación es de solo lectura.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
void imprimir_hex(void *buffer, size_t n);
```

### Código Conforme (Recomendado)

```{code-block} c
void imprimir_hex(const void *buffer, size_t n);
```
