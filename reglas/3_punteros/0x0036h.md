(0x0036h)=
# 0x0036h: Asigná NULL al puntero tras liberar un recurso opaco en el ámbito del cliente

```{admonition} Categoría: Punteros y Gestión de Memoria (0x30XX)
:class: note
Código de regla: `0x0036h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Al destruir o liberar una instancia de un tipo opaco mediante su función destructora, es mandatorio asignar `NULL` al puntero correspondiente en el código del cliente para mitigar el uso accidental de punteros colgantes o referencias inválidas.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
lista_destruir(mi_lista);
```

### Código Conforme (Recomendado)

```{code-block} c
lista_destruir(mi_lista);
mi_lista = NULL;
```
