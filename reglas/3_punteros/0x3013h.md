(0x3013h)=
# 0x3013h: Asignación de memoria con sizeof sobre puntero en lugar del tipo apuntado

```{admonition} Categoría: Punteros y Gestión de Memoria (0x30XX)
:class: note
Código de regla: `0x3013h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Al alocar memoria dinámica con 'ptr = malloc(...)', debe usarse 'sizeof(*ptr)' o 'sizeof(tipo)'. Usar 'sizeof(ptr)' reserva solo el tamaño del puntero (4 u 8 bytes) provocando desbordamientos.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int *arr = malloc(10 * sizeof(arr));
```

### Código Conforme (Recomendado)

```{code-block} c
int *arr = malloc(10 * sizeof(*arr));
```
