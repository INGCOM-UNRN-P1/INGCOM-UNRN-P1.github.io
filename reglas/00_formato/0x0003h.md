(0x0003h)=
# 0x0003h: Un espacio antes y después de cada operador binario

:::{admonition} Categoría: Sintaxis y formato visual (0x00XX)
:class: note
Código de regla: `0x0003h` | Soporta corrección automática: **Sí**

:::
<!-- {admonition} Categoría: Sintaxis y formato visual (0x00XX) -->

## Enunciado normativo

> **DEBE** dejarse exactamente un espacio en blanco antes y después de cada
> operador binario y entre una palabra clave de control y su paréntesis
> (`if (`, `for (`, `while (`, `switch (`). **NO DEBE** pegarse un operador
> binario a sus operandos.

La regla rige operadores aritméticos, relacionales, lógicos y de asignación.

## ¿Por qué existe esta regla?

### El problema

El ojo no lee caracteres aislados: reconoce bloques. Un operador pegado a sus
operandos (`a+b*c`) forma una mancha uniforme donde la precedencia
({ref}`0x1013h`) se vuelve difícil de verificar. El espacio separa
visualmente los términos de la operación y deja que la estructura de la
expresión emerja sin esfuerzo.

En las palabras clave de control el espacio cumple otra función: distingue la
palabra clave de una supuesta llamada a función. `if(x)` se lee como si `if`
fuera una función; `if (x)` lo identifica como estructura de control.

### Consecuencias de violarla

| Tipo de consecuencia | Efecto concreto |
| :--- | :--- |
| Compilación | Ninguna: la semántica no cambia. |
| Legibilidad | Las expresiones largas se vuelven ilegibles y esconden la precedencia. |
| Bug silencioso | Un error de precedencia (`a+b*c`) pasa desapercibido en la revisión. |
| Consistencia | El archivo mezcla zonas espaciadas y zonas comprimidas. |
| Revisión docente | La corrección visual y la comparación con la norma se dificultan. |

### Fundamento en el estándar y en la cátedra

El estándar trata los espacios como separadores sin valor semántico
(§6.4, tokens). La cátedra adopta el espaciado uniforme porque prepara al
estudiante para reconocer las unidades léxicas de C y porque es requisito de
otras reglas de espaciado del catálogo.

## Alcance y excepciones

Cubre operadores binarios (`+`, `-`, `*`, `/`, `%`, `=`, `==`, `<`, `&&`,
`||`, `|`, `&`, entre otros). No rige a los operadores unarios, regulados por
{ref}`0x000Ch` y {ref}`0x0016h`, ni a `->`, `.` ({ref}`0x000Bh`) ni a la coma
({ref}`0x000Dh`).

## Ejemplos exhaustivos

### ❌ Contraejemplo 1 — Toda la expresión comprimida

``` c
uno=dos+tres;
```
<!-- c -->

Por qué falla: no se distingue la asignación de la suma y el lector debe
aplicar la precedencia mentalmente para saber qué se asigna.

### ❌ Contraejemplo 2 — Condición sin espacios y palabra clave pegada

``` c
if(activo&&saldo>=limite){
```
<!-- c -->

Por qué falla: `if(` se confunde con una función, y `activo&&saldo>=limite`
oculta que hay dos operadores lógicos y uno relacional en juego.

### ✅ Ejemplo conforme 1 — Operadores separados

``` c
uno = dos + tres;
total = base * (1 + IVA);
```
<!-- c -->

Justificación: cada operador binario tiene un espacio a cada lado; los
paréntesis explicitan la agrupación de la suma.

### ✅ Ejemplo conforme 2 — Control con espacio y condición clara

``` c
if (activo && saldo >= limite)
{
    autorizar();
}
```
<!-- c -->

Justificación: el espacio tras `if` identifica la estructura y los
operadores relacional y lógico quedan visualmente separados.

### ⚠️ Casos límite

- **Unarios:** `-x`, `!flag`, `*ptr`, `&var` van pegados a su operando; no
  son binarios y no llevan espacio.
- **Cast:** en `(int) x` el espacio va después del paréntesis de cierre del
  cast, no dentro.
- **Alineación:** no se permite alinear con espacios extra; eso viola
  {ref}`0x000Fh`.

## Cómo detectarla

| Herramienta | Comando | Señal |
| :--- | :--- | :--- |
| `gaff` | `gaff check archivo.c` / `gaff fix archivo.c` | Regla 0x0003h: operador binario sin espacio. |
| `clang-format` | `clang-format --dry-run archivo.c` | Diferencias de espaciado respecto de la configuración. |
| `gcc` / `clang` | `gcc -Wall -Wextra -std=c11` | No detecta espaciado; sí advierte `-Wparentheses` por precedencia. |

## Checklist de autocontrol

- [ ] ¿Cada operador binario tiene un espacio a cada lado?
- [ ] ¿Escribí `if (`, `for (`, `while (`, `switch (` con espacio?
- [ ] ¿Dejé los unarios y `->` sin espacios?
- [ ] ¿Evité usar espacios para alinear columnas?

## Reglas relacionadas

* {ref}`0x0011h` — espaciado estricto entre palabra clave y paréntesis.
* {ref}`0x000Dh` — espacio obligatorio después de la coma.
* {ref}`0x000Eh` — sin espacios internos tras `(` ni antes de `)`.
* {ref}`0x000Fh` — prohibición de espacios múltiples.
* {ref}`0x1013h` — paréntesis aclaratorios en expresiones lógicas mixtas.
