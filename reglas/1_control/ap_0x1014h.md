(ap_0x1014h)=
# Antipatrón AP-0x1014h: Invocación a strlen() en condición de parada de bucle for

:::{admonition} Regla de Estilo Asociada: 0x1014h
:class: tip
La transgresión descripta en este antipatrón se encuentra normada por la **[0x1014h: Prohibición de expresiones de asignación dentro de estructuras de control](0x1014h.md)**.
:::

```{admonition} Diagnóstico de Antipatrón
:class: warning
Código de auditoría: `AP-0x1014h` | Categoría: Estructuras de Control y Lazos (0x10XX)
```


## Diagnóstico
Llamar a strlen() repetidamente en el bucle degrada la complejidad computacional a O(n^2).

## Justificación Pedagógica y de Estándar C
El código de diagnóstico `0x1014h` identifica una práctica desaconsejada en la arquitectura pedagógica de la materia.
Esta transgresión incrementa el acoplamiento, produce comportamiento indefinido o vulnera los invariantes de memoria.

## Sugerencia de Corrección
Guardá la longitud en una variable previa: 'size_t len = strlen(s); for (size_t i = 0; i < len; i++)'.

## Ejemplos

### Código con Antipatrón (Incorrecto)
```c
for (size_t i = 0; i < strlen(s); i++) { ... }
```

### Código Idiomático Refactorizado (Correcto)
```c
size_t len = strlen(s);
for (size_t i = 0; i < len; i++) { ... }
```
