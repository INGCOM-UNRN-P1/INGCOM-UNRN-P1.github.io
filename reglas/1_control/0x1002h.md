# 0x1002h: no uses el uso descontrolado de break y continue; preferí lazos con bandera de control

```{admonition} Categoría: Estructuras de Control y Lazos (0x10XX)
:class: note
Código de regla: `0x1002h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

La cátedra desaconseja el uso generalizado de `break` y `continue` para controlar lazos complejos. En su lugar, preferí usar variables booleanas (banderas) de control en la condición del lazo. **Excepción:** Se admite el uso de `break` para salir anticipadamente de un lazo cuando simplifique la lógica y mitigue un anidamiento excesivo o banderas redundantes. El uso de `continue` sigue estando estrictamente prohibido debido a que salta partes del código y oscurece el flujo lógico del lazo. (Si tenés dudas, consultá)

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
for (int i = 0; i < 10; i++) { if (i == 4) continue; }
```

### Código Conforme (Recomendado)

```{code-block} c
bool seguir = true;
while (i < 10 && seguir) { ... }
```
