(0x1008h)=
# 0x1008h: Toda instrucción switch debe incluir un caso default

```{admonition} Categoría: Estructuras de Control y Lazos (0x10XX)
:class: note
Código de regla: `0x1008h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Para proveer un comportamiento predecible y robusto, toda instrucción `switch` debe finalizar con un bloque `default`. Esto establece que el programa maneje explícitamente cualquier valor inesperado. Si un `case` intencionalmente no contiene una instrucción `break` para "caer" (`fall-through`) al siguiente caso, esta intención debe ser documentada con un comentario.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
switch (cmd) {
    case 1: ... break;
}
```

### Código Conforme (Recomendado)

```{code-block} c
switch (cmd) {
    case 1: ... break;
    default: ... break;
}
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
