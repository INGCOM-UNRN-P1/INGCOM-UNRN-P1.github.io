# Antipatrón AP-0x1016h: Uso de operador bit a bit (&, |) en condición lógica en lugar de booleano (&&, ||)

:::{admonition} Regla de Estilo Asociada: 0x1016h
:class: tip
La transgresión descripta en este antipatrón se encuentra normada por la **[0x1016h: Detector de expresiones booleanas complejas sin paréntesis aclaratorios](0x1016h.md)**.
:::

```{admonition} Diagnóstico de Antipatrón
:class: warning
Código de auditoría: `AP-0x1016h` | Categoría: Estructuras de Control y Lazos (0x10XX)
```


## Diagnóstico
Los operadores bit a bit no realizan evaluación en cortocircuito y pueden provocar desreferencias nulas o efectos colaterales no deseados.

## Justificación Pedagógica y de Estándar C
El código de diagnóstico `0x1016h` identifica una práctica desaconsejada en la arquitectura pedagógica de la materia.
Esta transgresión incrementa el acoplamiento, produce comportamiento indefinido o vulnera los invariantes de memoria.

## Sugerencia de Corrección
Utilizá los operadores lógicos '&&' o '||' con evaluación cortocircuitada.

## Ejemplos

### Código con Antipatrón (Incorrecto)
```c
if (a > 0 & b > 0) { ... }
```

### Código Idiomático Refactorizado (Correcto)
```c
if (a > 0 && b > 0) { ... }
```
