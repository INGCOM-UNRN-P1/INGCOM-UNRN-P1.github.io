# 0x100Ch: mitigar comparaciones en estilo Yoda ('CONST == variable')

```{admonition} Categoría: Estructuras de Control y Lazos (0x10XX)
:class: note
Código de regla: `0x100Ch` | Soporta corrección automática: **Sí**
```

## Fundamentación y Justificación Pedagógica

Las comparaciones en estilo Yoda ('NULL == ptr', '0 == x') dificultan la lectura natural del flujo lógico. Con compiladores modernos (-Wall), escribir 'variable == CONST' es seguro e idiomático.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
if (NULL == ptr || 0 == count) { ... }
```

### Código Conforme (Recomendado)

```{code-block} c
if (ptr == NULL || count == 0) { ... }
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
