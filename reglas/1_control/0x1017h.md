(0x1017h)=
# 0x1017h: Detector de operadores de incremento o decremento múltiples en una misma expresión

:::{seealso} Antipatrón Didáctico Relacionado
Para analizar contraejemplos de código estudiantil y diagnósticos de este defecto, consultá:
* **[AP-0x1017h: Ramas idénticas duplicadas en bifurcación if-else](ap_0x1017h.md)**
:::

```{admonition} Categoría: Estructuras de Control y Lazos (0x10XX)
:class: note
Código de regla: `0x1017h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Modificar la misma variable más de una vez mediante operadores de incremento o decremento dentro de una misma sentencia provoca comportamiento indefinido.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
x = i++ + ++i;
```

### Código Conforme (Recomendado)

```{code-block} c
i++;
j++;
x = i + j;
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
