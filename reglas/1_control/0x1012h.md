# 0x1012h: Prohibición de comparaciones encadenadas no idiomáticas en C (a < b < c)

```{admonition} Categoría: Estructuras de Control y Lazos (0x10XX)
:class: note
Código de regla: `0x1012h` | Soporta corrección automática: **Sí**
```

## Fundamentación y Justificación Pedagógica

En C las comparaciones encadenadas como 'a < b < c' no verifican la relación matemática conjunta, sino que evalúan '(a < b) < c' (comparando un booleano contra c). Deben escribirse explícitamente con '&&'.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
if (a < b < c)
if (0 <= x <= 10)
```

### Código Conforme (Recomendado)

```{code-block} c
if (a < b && b < c)
```
