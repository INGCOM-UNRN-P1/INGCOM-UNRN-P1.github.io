(ap_0x1001h)=
# Antipatrón AP-0x1001h: Punto y coma accidental tras condición de control

:::{admonition} Regla de Estilo Asociada: 0x1001h
:class: tip
La transgresión descripta en este antipatrón se encuentra normada por la **[0x1001h: Todas las estructuras de control deben utilizar llaves](0x1001h.md)**.
:::

```{admonition} Diagnóstico de Antipatrón
:class: warning
Código de auditoría: `AP-0x1001h` | Categoría: Estructuras de Control y Lazos (0x10XX)
```


## Diagnóstico
El punto y coma crea una sentencia vacía, haciendo que el bloque que le sigue se ejecute incondicionalmente.

## Justificación Pedagógica y de Estándar C
El código de diagnóstico `0x1001h` identifica una práctica desaconsejada en la arquitectura pedagógica de la materia.
Esta transgresión incrementa el acoplamiento, produce comportamiento indefinido o vulnera los invariantes de memoria.

## Sugerencia de Corrección
remové el ';' al final de la condición de control.

## Ejemplos

### Código con Antipatrón (Incorrecto)
```c
if (x > 0);
{
    hacer_algo();
}
```

### Código Idiomático Refactorizado (Correcto)
```c
if (x > 0)
{
    hacer_algo();
}
```
