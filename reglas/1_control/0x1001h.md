(0x1001h)=
# 0x1001h: Todas las estructuras de control deben utilizar llaves

Código de regla: `0x1001h` | Soporta corrección automática: **No**

## Fundamentación y Justificación Pedagógica

Aunque las llaves son opcionales para bloques de una sola línea, su uso es obligatorio para mantener la prolijidad y consistencia, y para mitigar que futuras modificaciones introduzcan comportamientos inesperados.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
if (x > 0)
    x++;
```

### Código Conforme (Recomendado)

```{code-block} c
if (x > 0)
{
    x++;
}
```
