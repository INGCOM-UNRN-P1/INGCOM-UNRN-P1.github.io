(0x1013h)=
# 0x1013h: Prohibición de saltos no estructurados goto fuera del patrón canónico de liberación de recursos

```{admonition} Categoría: Estructuras de Control y Lazos (0x10XX)
:class: note
Código de regla: `0x1013h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Los saltos con 'goto' hacia atrás (backwards jumps) simulando lazos no estructurados o saltos a etiquetas intermedias están estrictamente prohibidos. Solo se tolera excepcionalmente el salto hacia adelante a un bloque terminal de liberación de recursos.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
loop:
    // ...
    goto loop; // Salto hacia atrás prohibido
```

### Código Conforme (Recomendado)

```{code-block} c
if (!res) goto cleanup;
// ...
cleanup:
    free(p);
    return false;
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
