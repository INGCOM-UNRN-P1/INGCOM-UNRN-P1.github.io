(0x1011h)=
# 0x1011h: Prohibición de cláusula else redundante tras sentencia de retorno anticipado

```{admonition} Categoría: Estructuras de Control y Lazos (0x10XX)
:class: note
Código de regla: `0x1011h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Si una rama 'if' concluye incondicionalmente con 'return;', la cláusula 'else' posterior es redundante. Desanidá el flujo para mantener bajo el nivel de indentación.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
if (error) {
    return -1;
} else {
    procesar_exito();
    return 0;
}
```

### Código Conforme (Recomendado)

```{code-block} c
if (error) {
    return -1;
}
procesar_exito();
return 0;
```
