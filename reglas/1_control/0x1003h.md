# 0x1003h: Utilizá el lazo for para iteraciones con rango o contador definido y while para lazos controlados por condiciones lógicas

```{admonition} Categoría: Estructuras de Control y Lazos (0x10XX)
:class: note
Código de regla: `0x1003h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Utilizá el lazo `for` cuando la cantidad de iteraciones esté predefinida o se controle mediante un contador o rango conocido. Reservá el uso del lazo `while` para iteraciones basadas en condiciones puramente lógicas o eventos indefinidos en tiempo de ejecución. El lazo `for` es preferible para conteos, ya que agrupa la inicialización, la condición de parada y el incremento en un único lugar, mitigando lazos infinitos por olvido del incremento de control.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
for (scanf("%d", &n); n != 0; scanf("%d", &n)) { ... }
```

### Código Conforme (Recomendado)

```{code-block} c
while (numero != 0) { scanf("%d", &numero); }
```
