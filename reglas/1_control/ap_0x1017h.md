# Antipatrón AP-0x1017h: Ramas idénticas duplicadas en bifurcación if-else

:::{admonition} Regla de Estilo Asociada: 0x1017h
:class: tip
La transgresión descripta en este antipatrón se encuentra normada por la **[0x1017h: Detector de operadores de incremento o decremento múltiples en una misma expresión](0x1017h.md)**.
:::

```{admonition} Diagnóstico de Antipatrón
:class: warning
Código de auditoría: `AP-0x1017h` | Categoría: Estructuras de Control y Lazos (0x10XX)
```


## Diagnóstico
Tener bloques idénticos en ambas ramas invalida el propósito de la bifurcación condicional o denota un error tipográfico en una de las ramas.

## Justificación Pedagógica y de Estándar C
El código de diagnóstico `0x1017h` identifica una práctica desaconsejada en la arquitectura pedagógica de la materia.
Esta transgresión incrementa el acoplamiento, produce comportamiento indefinido o vulnera los invariantes de memoria.

## Sugerencia de Corrección
remové la estructura condicional si el comportamiento es uniforme o corregí la rama divergente.

## Ejemplos

### Código con Antipatrón (Incorrecto)
```c
if (x > 0) { total += x; } else { total += x; }
```

### Código Idiomático Refactorizado (Correcto)
```c
total += x;
```
