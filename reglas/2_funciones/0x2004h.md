(0x2004h)=
# 0x2004h: No se permite el uso de variables globales

```{admonition} Categoría: Funciones y Modularización (0x20XX)
:class: note
Código de regla: `0x2004h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Las variables globales pueden ser modificadas desde cualquier parte del programa, lo que causa efectos secundarios impredecibles y dificulta el rastreo de errores. **Su uso está estrictamente prohibido**.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int contador_global = 0;
```

### Código Conforme (Recomendado)

```{code-block} c
const double PI = 3.14159265;
#define BUFFER_MAX 1024
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
