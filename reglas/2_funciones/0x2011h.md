(0x2011h)=
# 0x2011h: Prohibición de reasignar o modificar parámetros recibidos por valor dentro de la función

:::{seealso} Antipatrón Didáctico Relacionado
Para analizar contraejemplos de código estudiantil y diagnósticos de este defecto, consultá:
* **[AP-0x2011h: Recursión mutua o cíclica sin caso base](ap_0x2011h.md)**
:::

```{admonition} Categoría: Funciones y Modularización (0x20XX)
:class: note
Código de regla: `0x2011h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Modificar un parámetro primitivo recibido por valor (ej: n = 10; n++) confunde el contrato de entrada. Copiá el valor a una variable local explícita si requerís mutabilidad.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int calcular(int limite) {
    while (limite > 0) limite--;
    return limite;
}
```

### Código Conforme (Recomendado)

```{code-block} c
int calcular(int limite) {
    int restante = limite;
    while (restante > 0) restante--;
    return restante;
}
```
