# 0x200Dh: Cada función debe tener a lo sumo un return

```{admonition} Categoría: Funciones y Modularización (0x20XX)
:class: note
Código de regla: `0x200Dh` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Cada función debe estructurarse con un único punto de retorno (`return`) para facilitar el seguimiento del flujo de control y proveer la liberación uniforme de recursos.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int calcular(int x)
{
    if (x > 0) {
        return x * 2;
    }
    return 0;
}
```

### Código Conforme (Recomendado)

```{code-block} c
int calcular(int x)
{
    int resultado = 0;
    if (x > 0) {
        resultado = x * 2;
    }
    return resultado;
}
```
