(0x2002h)=
# 0x2002h: Las funciones no deben contener printf o scanf, a menos que ese sea su propósito explícito

```{admonition} Categoría: Funciones y Modularización (0x20XX)
:class: note
Código de regla: `0x2002h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Las funciones deben desacoplarse de las operaciones de entrada y salida (I/O) para maximizar su reutilización y facilitar las pruebas unitarias. Si el propósito de una función no es realizar I/O, dichas llamadas deben ser delegadas a otras funciones especializadas del llamador.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
void calcular_iva(float monto) { printf("IVA: %f\n", monto * 0.21f); }
```

### Código Conforme (Recomendado)

```{code-block} c
float calcular_iva(float monto) { return monto * 0.21f; }
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
