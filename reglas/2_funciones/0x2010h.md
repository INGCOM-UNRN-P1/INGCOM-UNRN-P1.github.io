# 0x2010h: Prohibición de paréntesis superfluos en sentencia return

```{admonition} Categoría: Funciones y Modularización (0x20XX)
:class: note
Código de regla: `0x2010h` | Soporta corrección automática: **Sí**
```

## Fundamentación y Justificación Pedagógica

En lenguaje C, 'return' es una palabra clave de control de flujo, no una llamada a función. Los paréntesis envolventes ('return (x);') son redundantes y deben removerse.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
return (resultado);
```

### Código Conforme (Recomendado)

```{code-block} c
return resultado;
```
