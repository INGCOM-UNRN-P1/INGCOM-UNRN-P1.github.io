(0x200Fh)=
# 0x200Fh: Uso obligatorio de 'void' explícito en funciones sin parámetros

```{admonition} Categoría: Funciones y Modularización (0x20XX)
:class: note
Código de regla: `0x200Fh` | Soporta corrección automática: **Sí**
```

## Fundamentación y Justificación Pedagógica

En C estándar, una declaración 'int f()' indica un número indeterminado de parámetros (estilo K&R). Debe utilizarse siempre 'int f(void)' para declarar explícitamente ausencia de argumentos.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int obtener_contador();
```

### Código Conforme (Recomendado)

```{code-block} c
int obtener_contador(void);
```
