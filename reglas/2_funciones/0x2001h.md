(0x2001h)=
# 0x2001h: Las funciones deben usar cláusulas de guarda y retornos anticipados para mitigar la anidación profunda

```{admonition} Categoría: Funciones y Modularización (0x20XX)
:class: note
Código de regla: `0x2001h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Se admite el uso de retornos anticipados (`early returns`) al inicio de la función en forma de cláusulas de guarda (`guard clauses`) para validar parámetros o comprobar condiciones de error iniciales inmediatas. Esto mitiga la anidación profunda de bloques `if` (código en flecha) y mejora la comprensión visual del camino feliz del algoritmo. Sin embargo, en funciones más complejas donde se asignen recursos locales (memoria dinámica, archivos abiertos, sockets), se prefiere centralizar la limpieza al final de la función para mitigar fugas de recursos por puntos de salida prematuros alternativos.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
if (s != NULL) { if (s->activo) { if (s->val > 0) { ... } } }
```

### Código Conforme (Recomendado)

```{code-block} c
if (s == NULL) return -1;
if (s->activo == false) return -1;
```

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
