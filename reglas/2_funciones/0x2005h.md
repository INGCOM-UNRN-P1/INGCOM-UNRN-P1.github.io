# 0x2005h: Cada función debe tener una única responsabilidad (Principio de Responsabilidad Única)

```{admonition} Categoría: Funciones y Modularización (0x20XX)
:class: note
Código de regla: `0x2005h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Cada función debe encargarse de una sola tarea. Esto mejora la legibilidad, la reutilización y el mantenimiento del código. Las funciones pequeñas y especializadas son más fáciles de probar y depurar.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
Una función procesar_todo() de 60 líneas continuas.
```

### Código Conforme (Recomendado)

```{code-block} c
Dividir funciones complejas en funciones auxiliares privadas (static).
```
