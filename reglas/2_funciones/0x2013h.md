# 0x2013h: Tipo de retorno obligatorio 'int' en la función main()


## Fundamentación y Justificación Pedagógica

La función de punto de entrada 'main' debe declarar obligatoriamente 'int' como tipo de retorno conforme a los estándares ISO C99/C11/C23. El uso de 'void main' es inválido y no portable.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
void main(void)
{
}
```

### Código Conforme (Recomendado)

```{code-block} c
int main(void)
{
    return 0;
}
```
