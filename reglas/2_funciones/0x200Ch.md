(0x200Ch)=
# 0x200Ch: Prohibición de retornar la dirección de una variable local de stack

```{admonition} Categoría: Funciones y Modularización (0x20XX)
:class: note
Código de regla: `0x200Ch` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Retornar un puntero a una variable local de stack (&variable) genera un puntero colgante (dangling pointer) ya que el marco de activación se destruye al finalizar la función.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int *crear(void) {
    int x = 10;
    return &x;
}
```

### Código Conforme (Recomendado)

```{code-block} c
int *crear(void) {
    int *p = malloc(sizeof(int));
    return p;
}
```
