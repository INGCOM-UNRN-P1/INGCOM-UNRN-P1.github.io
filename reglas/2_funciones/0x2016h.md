(0x2016h)=
# 0x2016h: Detector de bloques else superfluos tras sentencias terminales

```{admonition} Categoría: Funciones y Modularización (0x20XX)
:class: note
Código de regla: `0x2016h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Si la rama 'if' finaliza con una sentencia incondicional de salida ('return', 'exit', 'break'), el bloque 'else' es superfluo y agrega anidamiento innecesario.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
if (error) {
    return -1;
} else {
    procesar();
}
```

### Código Conforme (Recomendado)

```{code-block} c
if (error) {
    return -1;
}
procesar();
```
