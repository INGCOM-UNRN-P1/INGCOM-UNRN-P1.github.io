# 0x400Ah: Prohibición de operar sobre flujos de archivo tras haber invocado fclose() (use-after-close)

## Fundamentación y Justificación Pedagógica

Utilizar un puntero a FILE* en funciones de E/S tras haber sido cerrado con fclose() provoca violaciones de segmento y corrupción del estado del runtime.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
FILE *f = fopen("log.txt", "r");
fclose(f);
fread(buf, 1, 10, f); // use-after-close
```

### Código Conforme (Recomendado)

```{code-block} c
FILE *f = fopen("log.txt", "r");
...
fclose(f);
f = NULL;
```
