(0x4006h)=
# 0x4006h: Prohibición del antipatrón while (!feof(f)) para control de fin de archivo


## Fundamentación y Justificación Pedagógica

La función 'feof()' solo retorna verdadero DESPUÉS de que una operación de lectura previa haya fallado al toparse con el fin de archivo. Usarla en la cabecera procesa el último registro dos veces.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
while (!feof(f)) {
    fgets(buf, sizeof(buf), f);
    procesar(buf);
}
```

### Código Conforme (Recomendado)

```{code-block} c
while (fgets(buf, sizeof(buf), f) != NULL) {
    procesar(buf);
}
```
