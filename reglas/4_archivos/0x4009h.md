(0x4009h)=
# 0x4009h: Prohibición de anidar llamadas a fopen() directamente dentro de funciones de E/S

```{admonition} Categoría: Gestión de Archivos y Errores (0x40XX)
:class: note
Código de regla: `0x4009h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Llamar a fopen() dentro del paso de parámetros de fread/fscanf impide comprobar si el retorno fue NULL y genera fugas de recursos al no existir puntero para fclose().

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
fscanf(fopen("data.txt", "r"), "%d", &x); // anidamiento inseguro
```

### Código Conforme (Recomendado)

```{code-block} c
FILE *f = fopen("data.txt", "r");
if (f) { fscanf(f, "%d", &x); fclose(f); }
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
