(0x4008h)=
# 0x4008h: Validación obligatoria del valor de retorno de fclose() en modo escritura

```{admonition} Categoría: Gestión de Archivos y Errores (0x40XX)
:class: note
Código de regla: `0x4008h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Al cerrar flujos de archivo abiertos para escritura ("w", "a", "wb"), fclose() puede fallar al vaciar el búfer del sistema operativo. Debe verificarse que retorne distinto de EOF.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
FILE *f = fopen("log.txt", "w");
...
fclose(f); // retorno ignorado en archivo de salida
```

### Código Conforme (Recomendado)

```{code-block} c
FILE *f = fopen("log.txt", "w");
...
if (fclose(f) == EOF) { perror("Error"); }
```
