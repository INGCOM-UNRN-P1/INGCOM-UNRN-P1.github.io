(0x4004h)=
# 0x4004h: mantené la simetría de recursos al abrir y cerrar archivos en el mismo nivel de abstracción

```{admonition} Categoría: Gestión de Archivos y Errores (0x40XX)
:class: note
Código de regla: `0x4004h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

La función que abre un archivo debe ser la misma responsable de cerrarlo, o bien se debe delegar formalmente su propiedad a una estructura/módulo administrador simétrico. Esto mitiga descriptores de archivo huérfanos que agoten el límite del sistema operativo.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
FILE *f = fopen(...); delegar(f); // Nadie cierra f
```

### Código Conforme (Recomendado)

```{code-block} c
void procesar() { FILE *f = fopen(...); ... fclose(f); }
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
