## Fundamentación y Justificación Pedagógica

Funciones como `fread`, `fwrite`, `fgetc`, `fgets`, `fprintf` y `fscanf` devuelven valores de control. Es obligatorio verificar dichos retornos para mantener transferencias completas e identificar fallos o el fin de archivo (EOF).

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
fread(buf, 1, 100, f); // Sin verificar si leyó
```

### Código Conforme (Recomendado)

```{code-block} c
size_t leidos = fread(buf, 1, 100, f);
if (leidos < 100) { ... }
```
