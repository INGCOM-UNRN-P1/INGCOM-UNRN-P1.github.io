(0x0028h)=
# 0x0028h: Detector de etiquetas de salto goto no alineadas al margen izquierdo

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x0028h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Las etiquetas de salto para gestión de errores deben situarse al margen izquierdo (columna 1) para facilitar su identificación visual como puntos de salto.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
    cleanup:
        free(buffer);
```

### Código Conforme (Recomendado)

```{code-block} c
cleanup:
    free(buffer);
    return;
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
