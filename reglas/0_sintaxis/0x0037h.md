(0x0037h)=
# 0x0037h: no uses identificadores genéricos con sufijo numérico o afijos (numero1, num_1, n_a, a_n)

```{admonition} Categoría: General
:class: note
Código de regla: `0x0037h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Los identificadores genéricos seguidos de un número o combinados con afijos (como 'numero1', 'numero_1', 'num1', 'n_a', 'a_n', 'var1', 'dato1', etc.) denotan una elección pobre de nombres y falta de abstracción. Usá nombres que reflejen el rol semántico específico o utilizá un arreglo si representan una colección.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int numero1 = 10, numero2 = 2;
int num_1 = 10, num_2 = 2;
int n_a = 10, a_n = 2;
```

### Código Conforme (Recomendado)

```{code-block} c
int dividendo = 10, divisor = 2;
int valores[2] = {10, 2};
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
