(0x0020h)=
# 0x0020h: Proporcionalidad en longitud de identificadores según su alcance

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x0020h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Los identificadores de alcance global, externo o nivel de archivo (variables globales y funciones públicas) deben tener nombres descriptivos con al menos 3 caracteres. Los identificadores breves o monocaracter se reservan exclusivamente para variables locales de iteración.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int x; // Variable global no descriptiva
void f(void); // Función pública no descriptiva
```

### Código Conforme (Recomendado)

```{code-block} c
int total_elementos = 0;
void inicializar_sistema(void);
```
