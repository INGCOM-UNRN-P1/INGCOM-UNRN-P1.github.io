(0x0016h)=
# 0x0016h: Prohibición de identificadores que colisionen con palabras clave o tipos estándar

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x0016h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

No utilizar palabras reservadas o tipos estándar de C99/C11/POSIX (restrict, inline, bool, true, false, nullptr, alignas) como nombres de variables o parámetros.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int bool = 1;
int restrict = 0;
```

### Código Conforme (Recomendado)

```{code-block} c
bool es_valido = true;
int limite = 10;
```
