# Antipatrón AP-0x0039h: Macro que ofusca sintaxis fundamental de C

:::{admonition} Regla de Estilo Asociada: 0x0013h
:class: tip
La transgresión descripta en este antipatrón se encuentra normada por la **[0x0013h: Las macros #define deben nombrarse en MAYUSCULAS_SNAKE_CASE](0x0013h.md)**.
:::

```{admonition} Diagnóstico de Antipatrón
:class: warning
Código de auditoría: `AP-0x0039h` | Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
```


## Diagnóstico
Ofuscar la sintaxis de C con macros personalizadas dificulta la lectura universal y perjudica el aprendizaje idiomático.

## Justificación Pedagógica y de Estándar C
El código de diagnóstico `0x0039h` identifica una práctica desaconsejada en la arquitectura pedagógica de la materia.
Esta transgresión incrementa el acoplamiento, produce comportamiento indefinido o vulnera los invariantes de memoria.

## Sugerencia de Corrección
Usá la sintaxis estándar de C sin envolver llaves ni operadores en macros.

## Ejemplos

### Código con Antipatrón (Incorrecto)
```c
#define BEGIN {
#define END }
```

### Código Idiomático Refactorizado (Correcto)
```c
// Usar bloques estándar { }
```
