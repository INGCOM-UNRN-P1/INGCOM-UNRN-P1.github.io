(0x0003h)=
# 0x0003h: Siempre debés inicializar las variables a un valor conocido

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x0003h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Es imperativo que una variable utilizada como R-Value contenga un valor conocido antes de su uso. Aunque un sistema operativo moderno pueda inicializar la memoria en `0`, la reutilización de la misma puede introducir valores residuales. No debés confiar en una inicialización implícita.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int contador;
struct datos_t d;
```

### Código Conforme (Recomendado)

```{code-block} c
int contador = 0;
struct datos_t d = {0};
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
