# 0x0000h: La claridad y prolijidad son de máxima importancia

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x0000h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

El código debe ser claro y fácil de entender para cualquier lector, no solo para su autor. Un código limpio y prolijo mitiga errores, facilita el mantenimiento y mejora la colaboración en equipo. La claridad es siempre preferible a técnicas de programación ofuscadas que solo complican la comprensión.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
for (int i=0,j=10;i<j;i++,j--) { printf("%d", i+j); }
```

### Código Conforme (Recomendado)

```{code-block} c
int i = 0;
while (i < limite) {
    printf("%d", i);
    i++;
}
```
