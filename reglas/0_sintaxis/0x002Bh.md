# 0x002Bh: Validador de espaciado en listas de argumentos y llamadas a funciones

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x002Bh` | Soporta corrección automática: **Sí**
```

## Fundamentación y Justificación Pedagógica

Toda coma en listas de parámetros o argumentos debe ir inmediatamente adherida al elemento anterior y seguida de un espacio en blanco ('f(a, b, c)').

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
calcular(x,y,z);
calcular(x , y);
```

### Código Conforme (Recomendado)

```{code-block} c
calcular(x, y, z);
```
