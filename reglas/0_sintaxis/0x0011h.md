(0x0011h)=
# 0x0011h: En archivos .c la inclusión de la cabecera propia debe figurar en primer lugar

```{admonition} Categoría: General
:class: note
Código de regla: `0x0011h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

En modulo.c, '#include "modulo.h"' debe ser la primera inclusión de usuario para mantener que el header sea autosuficiente.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
#include <stdio.h>
#include "otra_cosa.h"
#include "mi_modulo.h"
```

### Código Conforme (Recomendado)

```{code-block} c
#include "mi_modulo.h"
#include <stdio.h>
```
