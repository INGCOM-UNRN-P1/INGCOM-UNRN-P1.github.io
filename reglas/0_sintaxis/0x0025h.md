# 0x0025h: Validador de formato canónico en firmas de punteros a función

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x0025h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Las declaraciones y typedefs de punteros a función deben seguir el formato canónico 'tipo (*identificador)(params)' sin espacios dispersos alrededor del asterisco.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
typedef int (* operacion_t )(int, int);
```

### Código Conforme (Recomendado)

```{code-block} c
typedef int (*operacion_t)(int, int);
```
