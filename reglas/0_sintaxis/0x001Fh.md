(0x001Fh)=
# 0x001Fh: Prohibición de llaves redundantes en inicialización de tipos escalares

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x001Fh` | Soporta corrección automática: **Sí**
```

## Fundamentación y Justificación Pedagógica

El uso de llaves de inicialización de agregados ({0}) se reserva exclusivamente para structs y arreglos. Las variables escalares (enteros, caracteres, flotantes, punteros) deben inicializarse directamente con su valor literal sin llaves redundantes.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int contador = {0};
float tasa = {0.0};
```

### Código Conforme (Recomendado)

```{code-block} c
int contador = 0;
float tasa = 0.0f;
struct punto_t p = {0};
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
