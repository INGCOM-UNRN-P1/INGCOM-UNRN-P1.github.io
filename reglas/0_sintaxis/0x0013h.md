(0x0013h)=
# 0x0013h: Las macros #define deben nombrarse en MAYUSCULAS_SNAKE_CASE

:::{seealso} Antipatrón Didáctico Relacionado

:::

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x0013h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Las constantes y macros de preprocesador #define deben escribirse en mayúsculas sostenidas para distinguirlas visualmente de funciones e identificadores ordinarios.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
#define buffer_max 1024
```

### Código Conforme (Recomendado)

```{code-block} c
#define BUFFER_MAX 1024
```
