# 0x0001h: Los identificadores deben ser descriptivos

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x0001h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Los nombres de variables, funciones y demás identificadores deben reflejar con precisión su propósito. Esto contribuye a que el código sea autodescriptivo, minimizando la necesidad de comentarios adicionales. El uso de nombres significativos facilita la lectura y la comprensión.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int a = obtener_precio();
```

### Código Conforme (Recomendado)

```{code-block} c
int precio_total = obtener_precio();
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
