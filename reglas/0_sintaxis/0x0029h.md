(0x0029h)=
# 0x0029h: Auditor de inicialización de arreglos unidimensionales con exceso de elementos

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x0029h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

La lista de inicialización de un arreglo estático no debe contener más elementos que la dimensión explícita fijada en su declaración.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
int arr[3] = {1, 2, 3, 4}; // Excede dimensión
```

### Código Conforme (Recomendado)

```{code-block} c
int arr[3] = {1, 2, 3};
```
