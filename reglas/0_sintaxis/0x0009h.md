(0x0009h)=
# 0x0009h: Las líneas de código no deben exceder los 79 caracteres

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x0009h` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Nunca debés escribir líneas que excedan los 79 caracteres. El límite de 80 columnas es un estándar de facto que facilita la lectura y la visualización de código en paralelo. Las líneas largas fatigan la vista y requieren desplazamiento horizontal.

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
printf("Este es un mensaje de texto extremadamente largo que supera los ochenta caracteres en una sola línea.\n");
```

### Código Conforme (Recomendado)

```{code-block} c
printf("Mensaje largo dividido "
       "en dos líneas continuas.\n");
```

## Instrucción de Corrección

Aplique las directivas sugeridas o ejecute `gaff fix` para aquellas reglas que dispongan de corrección automatizada.
