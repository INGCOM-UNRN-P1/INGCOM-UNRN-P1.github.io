# 0x002Ch: Auditor de consistencia en nombres de constantes simbólicas

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x002Ch` | Soporta corrección automática: **No**
```

## Fundamentación y Justificación Pedagógica

Las constantes simbólicas declaradas con #define deben nombrarse enteramente en mayúsculas sostenidas con guiones bajos (SCREAMING_SNAKE_CASE).

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
#define buffer_size 1024
#define Max_Len 256
```

### Código Conforme (Recomendado)

```{code-block} c
#define BUFFER_SIZE 1024
```
