# 0x0022h: Validador de espaciado estricto en sentencias de control

```{admonition} Categoría: Sintaxis Básica y Nomenclatura (0x00XX)
:class: note
Código de regla: `0x0022h` | Soporta corrección automática: **Sí**
```

## Fundamentación y Justificación Pedagógica

Debe existir exactamente un espacio en blanco entre las palabras clave 'if', 'for', 'while', 'switch' y el paréntesis de apertura de su condición ('if (...)', no 'if(...)').

El cumplimiento de esta pauta establece la consistencia estilística requerida por la cátedra,
facilita la legibilidad para el equipo docente y minimiza errores sintácticos o semánticos en C.

## Ejemplos de Código

### Código No Conforme (Antipatrón)

```{code-block} c
if(x > 0) {
    return 1;
}
```

### Código Conforme (Recomendado)

```{code-block} c
if (x > 0) {
    return 1;
}
```
